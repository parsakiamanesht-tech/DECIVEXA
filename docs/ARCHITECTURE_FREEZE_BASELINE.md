## Governing Freeze Rules

1. AI is an intelligence layer and is not authoritative owner of user state.
2. Essential DECIVEXA functionality remains useful without continuous AI availability.
3. Security, privacy, performance and continuity are architectural properties.
4. Cross-domain context is minimum-sufficient, purpose-bound and policy-controlled.
5. User agency remains authoritative for consequential decisions.
6. Evidence Before Opinion and No Fabricated Certainty remain non-negotiable.
7. Historical facts and authoritative user decisions are never silently rewritten.
8. Material architecture, product direction, scope, security, privacy, data-authority or core-boundary changes require explicit Founder approval.
9. Deferred ideas remain in the Architecture Backlog until formally promoted.
10. Technology choices must demonstrate compliance with this baseline and must not silently redefine it.

## Technology Boundary

This baseline does **not** freeze a specific programming language, framework, database, ORM, cache, queue, cloud provider, AI model/provider, mobile framework or deployment topology. Those decisions require separate technical decision records.

## Immutability

This baseline identifier and version must be referenced by downstream implementation work. The content of this baseline must not be modified in place after Founder approval. Any material change requires a new baseline version and a new Founder approval record.
